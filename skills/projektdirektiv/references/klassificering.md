# Klassificering av uppdragsstorlek

## Poängsystem

Analysera automatiskt genom att räkna poäng per dimension:

| Dimension | Litet (1p) | Medelstort (2p) | Stort (3p) |
|-----------|-----------|----------------|------------|
| Budget | ≤ 300 tkr | 301–800 tkr | > 800 tkr |
| Timmar | ≤ 200h | 201–600h | > 600h |
| Tidsperiod | ≤ 2 månader | 3–6 månader | > 6 månader |
| Antal faser | 1–2 | 3 | 4+ |
| Intressenter | ≤ 5 | 6–15 | > 15 |

**Summering:**
- 5–8 poäng = **LITET** → 3–4 sidor
- 9–12 poäng = **MEDELSTORT** → 6–8 sidor
- 13+ poäng = **STORT** → 8–12 sidor

**Gränsfallsregel:** Om totalpoängen hamnar på övre gränsen för en storlek (8 eller 12) OCH minst två dimensioner poängsätts på nästa nivå: presentera båda alternativen och låt konsulten välja.

**Konsultens besked går före poängen.** Har konsulten själv angett storlek, till exempel "kort", "litet" eller en timvolym på högst 200 timmar, gäller det beskedet. Visa poängen, men ställ ingen gränsfallsfråga.

## Mallval

| Storlek | Mall | Filnamn |
|---|---|---|
| Litet | `Mall Uppdragsdirektiv Små uppdrag.docx` | `uppdragsdirektiv [Projektnamn] UTKAST.docx` |
| Medelstort | `Mall Projektdirektiv.docx` | `projektdirektiv [Projektnamn] UTKAST.docx` |
| Stort | `Mall Projektdirektiv.docx` | `projektdirektiv [Projektnamn] UTKAST.docx` |

Småmallen har redan rätt avsnitt för ett litet uppdrag och signeras av beställare och konsult. Den saknar styrgrupp, projektledning, projektgrupp och organisationstabell, så inget behöver rensas bort.

## Avsnitt för litet uppdrag (småmallen)

Avsnitten följer mallens ordning. Behåll mallens rubriker. Lägg inte till avsnitt som mallen saknar.

| Avsnitt i mallen | Omfattning |
|---|---|
| Uppdragsdirektivets syfte | Mallens standardtext, oförändrad |
| Bakgrund och syfte | 1–2 stycken |
| Mål med uppdraget | Punktlista (3–5) + mening om när uppdraget ska vara genomfört |
| Framgångsfaktorer | 3–4 punkter |
| Risker | 2–4 risker (tabell) |
| Genomförande | Stycke per fas med datum och avstämningspunkt, högst 3 faser |
| Leveranser | Punktlista |
| Avgränsningar | 4–6 punkter |
| Resursåtgång | Ekans timmar enligt avtalet + beställarens resurser per roll |
| Fastställande | Signering av beställare och konsult, egen sida |

Vilken definition i `skrivstilar.md` varje avsnitt följer står i avsnittet "Småmallen" där.

## Sektioner per storlek (medel och stort)

Gäller `Mall Projektdirektiv.docx`.

| Sektion | Medel | Stort |
|---------|-------|-------|
| Bakgrund och syfte | 2–3 stycken | 3–5 stycken med kontext |
| Projektmål | Mening + punktlista | Mening + detaljerad lista |
| Effektmål | ✅ Punktlista | ✅ Detaljerad lista |
| Framgångsfaktorer | 4–6 punkter | 6–8 punkter |
| Risker | 5–7 (tabell) | 8–12 (tabell m. sannolikhet) |
| Faser och beslutspunkter | Stycken per fas | Detaljerade stycken + kriterier |
| Leveranser | Punktlista med format | Punktlista med format |
| Avgränsningar | 4–6 punkter | 6–8 punkter |
| Tidplan | Löptext + lista | Löptext + tabell |
| Projektorganisation | Tabell | Tabell |
| Roller och ansvar | Anpassat per projekt | Detaljerat per roll |
| Intressenter | Punktlista med roll | Tabell namn/roll/intresse |
| Kopplingar | Om relevant | ✅ Alltid |
| Processpåverkan | Om relevant | ✅ Punktlista |
| Systempåverkan | Om relevant | ✅ Beskrivning |
| Resursåtgång | Extern + intern | Detaljerad med timmar/roll |
| Kostnader | Belopp + vad som ingår | Uppdelad kostnad + avgränsningar |
| Rapportering | Punktlista | Detaljerad struktur + frekvens |
| Kvalitetssäkring | Punktlista | Detaljerad plan |
| Ändringar | Kort beskrivning | Detaljerad process |
| Överlämning och projektavslut | Process + signering | Detaljerad process |
| Fastställande | ✅ Alltid — egen sida | ✅ Alltid — egen sida |
