# Kvalitetschecklista — Projektdirektiv

Kör denna checklista INNAN leverans. Varje punkt ska vara uppfylld.

**Litet uppdrag** (småmallen): kör bara avsnittet "Litet uppdrag" sist i filen. **Medel och stort:** kör alla övriga avsnitt.

## Innehållskvalitet

- [ ] Projektnamn konsistent överallt i dokumentet
- [ ] Bakgrund hämtad från källdokument + ev. komplettering från användaren
- [ ] Syfte hämtat direkt från förfrågningsunderlaget
- [ ] Projektmål beskriver förändrat verksamhetstillstånd — inte leveranser
- [ ] Effektmål (medel/stort) beskriver nytta efter projektavslut — inte projektresultat
- [ ] Innehållet nämner specifika system, dokument och processer
- [ ] Inga generiska fraser utan konkret specificering
- [ ] Leveranser specificerade — utgår från slutleverans
- [ ] Avgränsningar explicit listade (minst 4) — inga självklarheter
- [ ] Faser har beslutspunkter — enkla, inga oöverenskomna delleveranser
- [ ] Risker har hanteringsåtgärder (inte bara identifierade)
- [ ] Roller och ansvar anpassade efter faktisk projektorganisation
- [ ] Resursåtgång: intern timuppskattning per roll, extern hänvisar till avtal
- [ ] Kostnader: belopp och vad som ingår — inga timuppskattningar
- [ ] Realistisk tidplan med start-/slutdatum

## Rätt detaljnivå för storlek

- [ ] **Medel** (9–12p): 6–8 sidor, effektmål + projektorg + roller + rapportering + KS
- [ ] **Stort** (13+p): 8–12 sidor, allt ovan + intressenter (tabell) + kopplingar + ändringar (detaljerad)

## Format per sektion

- [ ] Bakgrund och syfte = LÖPTEXT
- [ ] Projektmål = Inledning + PUNKTLISTA
- [ ] Effektmål = Inledning + PUNKTLISTA (om medel/stort)
- [ ] Framgångsfaktorer = PUNKTLISTA
- [ ] Risker = TABELL
- [ ] Faser = LÖPTEXT (stycke per fas med beslutspunkt)
- [ ] Leveranser = PUNKTLISTA
- [ ] Avgränsningar = PUNKTLISTA
- [ ] Roller och ansvar = LÖPTEXT + PUNKTLISTA per roll
- [ ] Resursåtgång = MIX (löptext extern + lista intern)

## Formatering och layout

- [ ] Ekans mall använd som bas (logotyp, sidfot bevarad)
- [ ] Punktlistor formaterade med Word-listor (aldrig manuella bindestreck)
- [ ] Tabeller korrekt formaterade
- [ ] Inga placeholder-texter kvar utan anledning
- [ ] Eventuella `[ATT FYLLA I: ...]` har specifik anledning
- [ ] Försättsblad: Rubrik = projektnamn, Underrubrik = kundnamn
- [ ] Sidhuvud: Författare = PL, Ansvarig = UA, Version = datum

## Borttagna sektioner — bekräfta ej med

- [ ] Ingen Nyttoanalys
- [ ] Ingen Referenser-sektion
- [ ] Ingen Finansiering-sektion
- [ ] Ingen Projektdokument-sektion
- [ ] Inga sektioner med "ej tillämpligt"-innehåll kvar

## Litet uppdrag (småmallen)

Gäller `Mall Uppdragsdirektiv Små uppdrag.docx`. Kontrollerna om projektorganisation, roller, effektmål, kostnader och borttagna sektioner ovan gäller inte, eftersom mallen saknar de avsnitten.

**Innehåll**
- [ ] Projektnamn konsistent överallt, även på försättsbladet och i sidhuvudet
- [ ] Bakgrund hämtad från källdokument + ev. komplettering från konsulten
- [ ] Syfte hämtat direkt från förfrågningsunderlaget eller avtalet
- [ ] Mål med uppdraget beskriver förändrat verksamhetstillstånd, inte leveranser, och anger när uppdraget ska vara genomfört
- [ ] Framgångsfaktorer är förutsättningar utanför uppdragets kontroll, inte mallens exempel
- [ ] Risker har hanteringsåtgärder
- [ ] Genomförande: högst 3 faser, varje fas med datum och avstämningspunkt. Ingen veckotabell
- [ ] Leveranser utgår från slutleveransen
- [ ] Avgränsningar explicit listade (minst 4), inga självklarheter
- [ ] Resursåtgång: Ekans timmar enligt avtalet + beställarens resurser per roll. Inga belopp
- [ ] Inga interna Ekan-processer
- [ ] Inga avsnitt tillagda som mallen saknar

**Format**
- [ ] Bakgrund och syfte = LÖPTEXT
- [ ] Mål med uppdraget = Inledning + PUNKTLISTA + mening om slutdatum
- [ ] Framgångsfaktorer, Leveranser, Avgränsningar = PUNKTLISTA (Word-listor)
- [ ] Risker = TABELL
- [ ] Genomförande = LÖPTEXT, stycke per fas

**Mallrester borta**
- [ ] Inga `<...>`-placeholders kvar, inte heller `<xxx timmar.>` mitt i meningen under Resursåtgång
- [ ] Mallens exempelrader och deras punkter borta: "Exempel på framgångsfaktorer...", "Exempel på risker...", "Vanliga leveranser...", "Viktigt då detta säkerställer..."
- [ ] Inga tomma `Liststycke`-stycken kvar
- [ ] Datum ifyllda och gulmarkering borttagen: `ÅÅÅÅ-MM-DD` på försättsbladet, `ÅÅ-MM-DD` i sidhuvudet
- [ ] Sidhuvud: Dokument = projektnamn, Författare = konsulten, Ansvarig = UA
- [ ] Ort vald och år ifyllt (`Göteborg/Stockholm 20XX-` ersatt), dag och månad tomma för signeringen
- [ ] Försättsblad: Rubrik = projektnamn, Underrubrik = kundnamn
- [ ] Signaturtabellen har beställarens och konsultens namn
- [ ] Fastställande på egen sida
- [ ] Eventuella `[ATT FYLLA I: ...]` har specifik anledning
